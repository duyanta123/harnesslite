## 功能范围（冻结清单，来源=v1 功能盘点）

1. **dsh 运行时**：npm 安装 `@deepseek-ai/dsh@0.1.1-rc.2`（staging/backup 安装事务、崩溃日志、离线包机制）→ supervisor 启动 `node bin.js --profile <p> --patch <patch> web --no-open --host 127.0.0.1 --port 随机` → stdout 就绪解析 + 10s 健康探测(3次未中=重启) + 退避重启 [500ms,1s,2s,5s,10s] + Job Object 全树回收
2. **Node 管理**：检测（PATH/nvm/fnm/volta）+ 官方 release index 下载（SHA-256、进度事件）+ 选择持久化 `node-selection.json`
3. **项目管理**：`Project{id,name,path,profile,lastOpenedAt}` → `projects.json` 原子写；路径安全校验（拒绝网络盘/可移动盘）；加项目自动建 profile；绑定级联（改名/删除保护）；切换 = stop→start
4. **Profile 管理**：`~/.dsh/profiles` 编排；CRUD/复制/重命名(4阶段回滚)/对比(Standing)/声明导出导入(SHA-256 信封)；`profile.json {schema:2, active, pending, lastKnownGood}` 就绪才生效，失败回滚+恢复中心
5. **插件市场**：内置目录源 = **npm registry**（用户配置的 registry，默认激活）+ **awesome-dsh**（`awesome-dsh-plugin.com/plugins.json`，2937 插件、每日 CI 刷新、npm 映射+23 分类中英文案）+ **DSH 1024Store**（`deepseek1024.com/api/v1/plugins`，verified/unverified 校验、安装遥测）+ **自定义 standard-http-v1 源**（≤12）；三个内置源适配器新写（JSON → 本地索引搜索，只建议精确 npm 包名+版本）；preflight 隔离预检 → 意图令牌(2min) 确认 → `dsh plugin add/remove`（壳从不自行解析包）；停用重断言、安装回执、崩溃恢复日志、源健康探测
   **自定义源审核机制**：准入（强制 HTTPS + 合同探测：schema/字段/超时/体积上限，不合格拒收；运行中合同违规熔断自动停用标红）；**默认关闭**（设置中显式开启并说明风险）；信任分级（源标层级：内置×3 / 自定义-未审核；条目标可信度：1024Store verified/unverified、npm 映射有无、自定义源条目一律 unverified）；安装强化（确认框显著标注"来源：自定义源（未审核）"；npm registry 元数据交叉核对——首次发布时间/周下载量/关联仓库；自定义源条目逐条确认不支持批量）；红线不变（源永不接触代码/命令/URL，只建议精确 npm 包名+版本）
6. **终端**（已确认按 v1 原样保留）：窗口内真实系统终端多标签（ConPTY + xterm.js），每会话读写/等待三线程，独立 ProcessGuard 回收（停 harness/关应用不误杀用户进程），cwd 跟随项目，dsh 环境自动注入（PATH + DSH_* 变量），pwsh→powershell→cmd 回退，增量 UTF-8 解码、切面板滚动缓冲区不丢
7. **会话库**：直读 `~/.dsh/sessions/**`（Zstd JSONL、96MiB LRU）；roster/全文搜索/阅读/导出 MD·HTML·JSON；完成/失败 OS 通知；费用报表（本地费率）
8. **远程**：LAN 反向代理（TCP 中继 HTTP+SSE+WS）+ QR 配对（2分钟一次性码）+ 每设备可吊销凭据；supervisor 非 Ready 自动关闭
9. **桌面桥**：iframe postMessage letterbox（hello/notify/pick/badge/profiles/plugins/workspace）+ `HARNESSLITE_*` 环境变量注入 + 新写 `@duyanta123/harnesslite-integration` cordis 注入包（--patch，暴露只读 harnessLiteHost 服务）
10. **壳**：托盘、单实例、多窗口（placement 持久化）、自定义标题栏、深链、全局快捷键(Ctrl+Shift+D)、自启动、通知偏好、恢复中心、三步引导、Ctrl+K 命令面板、中英 i18n、Mica/Acrylic 材质、诊断导出（脱敏）
11. **预设/启动设置**：`~/.dsh/.agent-presets` 选择器；`startup.json`（快捷键/通知/固定端口/日志级别）


**人工 GUI 验收（一次性，全部开发完成后）**：Phase 6 结束后你统一走查——安装并对话、管理面全功能清单、双击安装版/绿色版、进程回收、单实例、托盘/快捷键等终验项

**网络问题处理**：npm / nodejs.org / 插件市场源访问失败或超时时，配置**临时**代理后重试（仅会话级环境变量，不写入任何配置文件）：
```powershell
$env:HTTP_PROXY="http://127.0.0.1:7877"
$env:HTTPS_PROXY="http://127.0.0.1:7877"
```
（Git Bash 中等价写法：`export HTTP_PROXY=http://127.0.0.1:7877 HTTPS_PROXY=http://127.0.0.1:7877`；npm / cargo / curl 均遵循这两个变量）
