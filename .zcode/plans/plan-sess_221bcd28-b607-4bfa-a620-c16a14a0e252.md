# 更新器 + 诊断入口（v0.1.2）

## 背景（调研结论）

前端更新链路已 100% 就位（`state/update.ts` 状态机、`lib/updater.ts` 包装、StatusBar 的"有新版本"提示、App 的 6 小时轮询都是携带来的），但 **Rust 侧三件套全缺**：`tauri-plugin-updater` 未注册、`tauri.conf.json` 无 `plugins.updater` 配置、CI 无签名密钥——所以前端所有更新调用今天都发不出去。诊断命令（`report_build/save/archive`）后端已通，只缺 UI 入口（v1 在 AboutPane，未携带）。另发现 capabilities 只给了 `core:default`，**真实桌面里 dialog/opener/clipboard 的调用全会被拒**——这次一并修。

## 一、更新器（照 v1 已验证模式）

1. **生成 minisign 密钥对**（空密码，v1 同款约定）：`pnpm tauri signer generate` → 私钥存 `C:\Users\duyan\.tauri\harnesslite.key`（不入库），`gh secret set TAURI_SIGNING_PRIVATE_KEY` 写入仓库 secret
2. **tauri.conf.json**：`bundle.createUpdaterArtifacts: true` + `plugins.updater { pubkey, endpoints: ["https://github.com/duyanta123/harnesslite/releases/latest/download/latest.json"], windows.installMode: "passive" }`（passive = 自动下载带进度条，用户只确认一次）
3. **Rust**：Cargo.toml 加 `tauri-plugin-updater = "2"`，lib.rs 注册
4. **capabilities/default.json**：补 `updater:default`、`process:default`（relaunch 需要）、`dialog:default`、`opener:default`、`clipboard-manager:allow-read-text`（修潜伏 bug）
5. **scripts/make-updater-manifest.mjs**（新）：从构建产物读 `.sig` 签名 + tauri.conf.json 的版本/pubkey → 生成 `latest.json`（windows-x86_64 条目，URL 指向 release 资产）
6. **release.yml**：构建步骤注入 `TAURI_SIGNING_PRIVATE_KEY`（空密码 env），构建后跑 manifest 生成器，上传清单加 `latest.json` + `*.sig`；`verify-release-assets.mjs` 增加"tag 构建必须有 latest.json 和 .sig"的门槛
7. 本地 `--no-sign` 构建不受影响（跳过签名）

## 二、诊断入口（Dashboard，自己的壳文件，不动携带组件）

Dashboard 日志区标题行右侧加两个 ghost 按钮（i18n 的 `about.*` 键全部现成，无需新增）：
- **复制报告**：`reportBuild()` → `navigator.clipboard.writeText(report.text)` → 已复制提示（按钮文案用 `about.reportCopy`）
- **导出 ZIP**：`plugin-dialog` save（默认名 `report.archiveName`、zip 过滤）→ `reportArchive(path, text)` → `revealItemInDir`（v1 AboutPane 同款流程，用 `about.reportSave`）

## 三、发布 v0.1.2（证明整条链）

更新器只有发一次带签名的 release 才算被证明。实现完成后：版本升 0.1.2 → 提交推送 → 打 tag → CI 产出带 `.sig` + `latest.json` 的签名安装包。**注意：0.1.1 里没有更新器，你需要手动装一次 0.1.2，之后 0.1.3 起全自动。**

## 验证

- 本地：cargo test 全绿 + tsc + vitest 全绿；`tauri build --no-sign` 确认配置可用；manifest 生成器用假 .sig 验 JSON 形状
- CI：Release workflow 全绿且资产含 `latest.json` + `.sig`
- 真实验证：装 0.1.2 后，StatusBar 在下一个版本发布时应出现更新提示（到 0.1.3 时可实测自动更新全链）

## 交付后你拿到什么

装一次 0.1.2 之后：以后每次我打新 tag，你机器上的 HarnessLite 会在 6 小时内（或重启时）自己弹"有新版本"，点一下自动下载安装重启；诊断 ZIP 一键导出可直接贴 issue。
